Отлично, страница открылась — значит:

маршрут работает
контроллер работает
модель Note работает
таблица mvc.mvc_demo_notes видится
view подключился

Но по скрину вижу странность: в таблице есть строка с кнопкой Удалить, а данные пустые. Это значит, что в таблице уже есть запись, но поля либо пустые, либо ключи массива приходят не так, как мы ожидаем.

Давай быстро проверим.

1. В pgAdmin выполни

SELECT *
FROM mvc.mvc_demo_notes
ORDER BY id DESC;

Если там есть пустая строка, можешь очистить таблицу:

TRUNCATE TABLE mvc.mvc_demo_notes RESTART IDENTITY;

После этого обнови /notes.


---

2. Проверь создание заметки

На странице введи:

Название: Тестовая заметка
Текст: Проверка записи в PostgreSQL

Нажми Создать заметку.

Если заметка нормально появится — всё хорошо.

Если снова будет пустая строка, тогда проблема в названиях ключей массива. Тогда заменим кусок в Views/notes/index.php на универсальный вариант.


---

3. Универсальный вариант вывода строки

В файле:

/local/mvc_demo/Views/notes/index.php

внутри цикла:

<?php foreach ($notes as $note): ?>

перед <tr> добавь:

<?php
$noteId = $note['id'] ?? $note['ID'] ?? '';
$noteTitle = $note['title'] ?? $note['TITLE'] ?? '';
$noteBody = $note['body'] ?? $note['BODY'] ?? '';
$noteCreatedAt = $note['created_at'] ?? $note['CREATED_AT'] ?? '';
?>

И ниже замени выводы:

<?= e($note['id'] ?? '') ?>
<?= e($note['title'] ?? '') ?>
<?= e($note['body'] ?? '') ?>
<?= e($note['created_at'] ?? '') ?>

на:

<?= e($noteId) ?>
<?= e($noteTitle) ?>
<?= e($noteBody) ?>
<?= e($noteCreatedAt) ?>

А в ссылке удаления замени:

(int)($note['id'] ?? 0)

на:

(int)$noteId
